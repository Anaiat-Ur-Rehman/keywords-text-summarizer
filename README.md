# Keywords & Text Summarizer

A lightweight, mobile-friendly Python tool designed to extract key terms and generate concise text summaries using frequency analysis and Regular Expressions.

## Features
- Extracts top keywords by filtering common stop words and filtering text patterns.
- Performs lightweight sentence-based text summarization.
- Self-contained script (`text_summarizer.py`) optimized for mobile execution.

## Tech Stack
- Python
- Regular Expressions (Regex) & Collections
